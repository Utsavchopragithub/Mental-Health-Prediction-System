# Mental Health Prediction System

# Overview
This project focuses on analyzing mental health data to uncover meaningful insights and build predictive models. It combines data analysis, visualization, dashboarding, and machine learning techniques to understand patterns and trends in mental health.

# Features
-  Exploratory Data Analysis (EDA)
-  Data Visualization
-  Interactive Dashboard
-  Machine Learning Models
-  Mental Health Prediction System
-  Insight Generation

# Tech Stack
- **Programming Language** : Python  
- **Libraries** : Pandas, NumPy  
- **Visualization** : Matplotlib, Seaborn  
- **Machine Learning:** Scikit-learn  
- **Dashboard:** Power BI / Tableau (if used)  
- **Environment:** Jupyter Notebook

## Project Structure

```
mental-health-prediction-system/

├── dashboard/         # Dashboard files (Power BI / Tableau)

└── requirements.txt   # Dependencies
```
